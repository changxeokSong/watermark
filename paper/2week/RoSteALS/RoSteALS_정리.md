## 1. 이 논문을 읽기 전에 — 배경 지식

### 1.1 스테가노그래피(Steganography)와 워터마킹이란?

```
스테가노그래피:
  커버(cover) 이미지 + 비밀(secret) 메시지
        ↓
  스테고(stego) 이미지  (시각적으로 커버와 구분 불가)
        ↓
  디코더 → 비밀 메시지 복원

워터마킹은 스테가노그래피의 특수 형태:
  - 저작권 보호, 콘텐츠 출처 증명(C2PA), AI 생성 이미지 표시 등에 활용
  - 공격(JPEG 압축, 자르기, 블러 등)에도 비밀이 살아남아야 함
```

**세 가지 핵심 목표:**
1. **페이로드(payload):** 얼마나 많은 비트를 숨길 수 있는가
2. **비가시성(imperceptibility):** 숨긴 흔적이 보이지 않아야 함
3. **견고성(robustness):** 이미지가 변형돼도 비밀을 복원할 수 있어야 함

---

### 1.2 VQGAN이란?

Esser et al. (2020)이 제안한 고해상도 이미지 합성을 위한 오토인코더 + 트랜스포머 프레임워크다.

```
VQGAN 구조:
  이미지 x (H×W×C)
        ↓  인코더 E
  연속 잠재 코드 z ∈ R^{H'×W'×C}   (H', W'는 H, W의 1/4 ~ 1/8)
        ↓  (양자화: 코드북 조회)
  이산 잠재 코드 z_q
        ↓  디코더 G
  재구성 이미지 x̄ = G(z_q)
```

**RoSteALS에서 중요한 관찰:**
- `G(z + ε) ≈ x` : 잠재 코드에 작은 노이즈 ε을 더해도 출력 이미지가 거의 변하지 않음
- 동일한 종류의 노이즈 ε은 이미지 콘텐츠와 무관하게 동일한 시각적 변화를 일으킴
- → 잠재 코드가 비밀 삽입에 적합한 공간임을 시사

---

### 1.3 KL-f8 오토인코더 (Stable Diffusion의 백본)란?

Rombach et al. (2022)의 Latent Diffusion Model(LDM)에서 사용하는 오토인코더다.

```
KL-f8:
  입력 512×512 이미지
        ↓  인코더
  64×64×4 잠재 코드 (8배 다운샘플)
        ↓  디코더
  512×512 이미지 재구성

차이점 vs VQGAN:
  - 양자화(quantization) 없음 → Kullback–Leibler divergence로 규제
  - Stable Diffusion v1.5와 동일한 백본 → 텍스트 기반 스테가에 활용
```

---

### 1.4 Latent Diffusion Model (LDM)이란?

Rombach et al. (2022)이 제안한, 픽셀 공간이 아닌 잠재 공간에서 확산(diffusion)을 수행하는 생성 모델이다.

```
LDM 학습:
  z_T ~ N(0, I)
        ↓  반복 노이즈 제거 (UNet)
  z_{T-1} → z_{T-2} → ... → z_0
        ↓  디코더 G
  이미지 x

조건부(text-based):
  텍스트 프롬프트 → CLIP 텍스트 인코더 → 크로스 어텐션으로 UNet 안내
```

**RoSteALS와의 연결:**
- LDM과 RoSteALS가 동일한 오토인코더 {E, G}를 공유
- LDM으로 생성한 잠재 코드에 RoSteALS의 비밀 오프셋 δ를 더하면 커버 없이 스테고 이미지 생성 가능

---

### 1.5 LPIPS (Learned Perceptual Image Patch Similarity)란?

Zhang et al. (2018)이 제안한, 사람이 느끼는 이미지 품질 차이를 신경망 특징으로 측정하는 지표다.

```
LPIPS(x, x̃):
  VGG/AlexNet 여러 레이어의 특징 차이를 가중 평균
  → 0에 가까울수록 지각적으로 유사
  → MSE보다 인간 판단과 상관관계가 높음

RoSteALS에서:
  품질 손실 L_quality의 핵심 구성 요소로 사용
  → 픽셀 수준 차이(MSE)와 지각적 차이(LPIPS)를 모두 고려
```

---

### 1.6 YUV 색공간이란?

RGB가 아닌 밝기(Y)와 색차(U, V)를 분리한 색공간이다.

```
RGB → YUV 변환:
  Y = 0.299R + 0.587G + 0.114B  (밝기, 지각적으로 가장 중요)
  U = -0.14713R - 0.28886G + 0.436B
  V = 0.615R - 0.51499G - 0.10001B

이점:
  - 인간 시각은 밝기(Y)에 민감, 색차(U,V)에 덜 민감
  - MSE를 YUV에서 계산 → 지각적으로 더 균일한 품질 손실
```

---

### 1.7 ImageNet-C 노이즈란?

Hendrycks & Dietterich (2019)가 모델 견고성 평가를 위해 정의한 15가지 공통 변형(corruption)의 표준 벤치마크다.

```
3가지 그룹:
  미분 가능(differentiable):
    - Brightness, Saturation, Contrast (선형 변환)
  미분 근사 가능:
    - JPEG Compression (미분 불가 → differentiable 근사 사용)
  비미분(non-differentiable):
    - Spatter, Frost, Fog, Shot noise, Impulse noise, Speckle noise
    - 처리 방식: n(x) = x + [n(x) - x]  ([.] = gradient 차단)

RoSteALS는 14가지 노이즈를 학습에 활용 (총 15개 중 1개 제외)
```

---

### 1.8 BCH 오류 정정 코드(ECC)란?

Bose-Chaudhuri-Hocquenghem 코드는 디지털 통신에서 비트 오류를 수정하는 코드다.

```
원리:
  100비트 메시지 → BCH 인코딩 → 더 긴 코드워드
  전송 중 일부 비트 오류 발생
  → BCH 디코딩으로 오류 비트 위치 파악 및 수정

RoSteALS에서:
  스테고 이미지에서 복원한 비트에 오류가 일부 있어도 원본 메시지 복원
  → Bit acc. (ECC) 지표: ECC 적용 후 복원 정확도
  → RoSteALS는 Bit acc. 0.94 → ECC 후 1.00 달성
```

## 2. 논문이 해결하려는 문제

### 2.1 기존 방법의 세 가지 한계

```
문제 1: 학습 복잡도
  기존 방법(HiDDeN, StegaStamp, RivaGAN):
    커버 이미지 분포 학습 + 비밀 삽입 학습을 동시에 수행
    → 수백 epoch 학습 필요 (RivaGAN: 300 epoch)
    → 대용량 학습 데이터와 큰 모델 필요

문제 2: 도메인 특화
  커버 이미지와 비밀을 함께 인코딩(e.g., UNet + skip connection)
  → 학습 도메인 밖 이미지에서 성능 저하
  → 좁은 도메인(얼굴, 자연 이미지)에 편향

문제 3: 견고성 부족
  공격에 취약 → 특히 블러, JPEG 압축, 강한 이미지 변형에서 성능 급락
  손으로 만든 방법(LSB, dwtDctSvd): 아예 노이즈에 설계가 맞지 않음
```

### 2.2 RoSteALS의 목표

```
목표 1: 경량 학습
  사전 학습된 오토인코더를 동결(freeze)
  → 이미지 분포 학습 불필요
  → 비밀 인코더(F)만 학습: 300K 파라미터, ~18 epoch

목표 2: 커버 이미지 독립적 비밀 삽입
  δ = F(s): 비밀 s만으로 잠재 오프셋 생성
  → 어떤 커버 이미지에도 동일하게 적용 가능
  → 학습 도메인 밖 이미지에서도 일반화

목표 3: 높은 견고성
  14가지 ImageNet-C 노이즈를 학습에 포함
  → 비트 정확도(Bit acc.) 분야 최고 달성
```

## 3. 관련 연구 심층 분석

### 3.1 손으로 만든 방법 (Hand-crafted Methods)

**LSB (Least Significant Bit) [Wolfgang & Delp 1996]:**
```
원리: 각 픽셀의 최하위 비트에 비밀 삽입
장점: 큰 페이로드, 완벽한 비가시성
단점: 노이즈에 극도로 취약 (JPEG 1번에 파괴)
```

**dwtDctSvd [Navas et al. 2008]:**
```
원리: DWT → DCT → SVD 순서로 변환 후
     YUV 공간의 U 프레임에 비밀 삽입
장점: LPIPS 품질 지표에서 우수
단점: 견고성 부족 (Bit acc. 0.61 vs RoSteALS 0.94, CLIC)
```

---

### 3.2 HiDDeN [Zhu et al., ECCV 2018]

**구조:**
```
커버 이미지 + 비밀 메시지
        ↓  인코더(CNN)
스테고 이미지
        ↓  노이즈 레이어 (JPEG 시뮬레이션, 가우시안 등)
        ↓  디코더(CNN)
복원된 비밀 메시지
        ↓  적대적 판별기로 스테고 품질 보장
```

**RoSteALS와의 차이:**
| 항목 | HiDDeN | RoSteALS |
|------|--------|---------|
| 이미지 분포 학습 | 인코더가 직접 학습 | 동결된 오토인코더 재사용 |
| 학습 epoch | 많음 | ~18 epoch |
| 도메인 일반화 | 제한적 | 광범위 (VQGAN 덕분) |

---

### 3.3 StegaStamp [Tancik et al., CVPR 2020]

**핵심 특징:**
```
UNet 기반 인코더 + ResNet 디코더
물리적 촬영(카메라 재촬영) 견고성에 특화 설계
```

**RoSteALS와의 비교:**
- SSIM 지표에서 StegaStamp가 소폭 우세 (이유: UNet skip connection → 픽셀 수준 세부 사항 보존)
- 그러나 견고성(Bit acc.)에서 RoSteALS가 전면 우세
- SIFID 지표에서 StegaStamp가 가장 불량 (시각적 아티팩트 발생, Figure 3 참고)

---

### 3.4 RivaGAN [Zhang et al., arXiv 2019]

**핵심 특징:**
```
GAN 기반 + 어텐션 메커니즘 + 적대적 학습
어텐션으로 비밀을 시각적으로 중요한 영역에 집중 삽입
```

**한계:**
- 300 epoch 학습 필요
- 견고성(Bit acc. 0.77, CLIC) → RoSteALS(0.94)보다 낮음
- 학습 도메인 밖 일반화 제한

---

### 3.5 SSL [Fernandez et al., ICASSP 2022]

**핵심 특징:**
```
사전 학습된 DINO ResNet-50의 특징 공간에서
역전파로 픽셀을 직접 최적화 (on-the-fly optimization)
```

**한계:**
- 이미지마다 100회 역전파 → 속도 느림
- 블라인드 설정(비밀 키 없이)에서 동작 불가
- 좁은 도메인(CLIC)에서 PSNR/SSIM 최고, 그러나 MetFACE(얼굴 예술)에서 SIFID 열세
  → 사전 학습된 특징 추출기가 RoSteALS의 VQGAN만큼 일반화되지 않음
- 견고성 최하 (Bit acc. 0.62, CLIC)

---

### 3.6 커버리스 스테가노그래피 선행 연구

**기존 방법:**
```
[Zhou et al. 2015]: 픽셀 값 해시로 이미지-비밀 인덱싱
[Zhou et al. 2017, 2018]: HOG, BoW 기반 해시
[Duan & Song 2018], [Volkhonskiy et al. 2020]: GAN 잠재 노이즈 → 비밀 변환
[Liu et al. 2022]: 분리된 구조-질감 오토인코더 (좁은 도메인 한정)
```

**RoSteALS의 차별점:**
- 오토인코더 잠재 공간의 오프셋으로 비밀 표현
- 어떤 잠재 코드에도 독립적으로 적용 가능
- LDM 생성 잠재 코드와 결합 → 고품질 이미지 생성

## 4. 핵심 아이디어: 왜 잠재 공간인가

### 4.1 핵심 관찰 두 가지 (Section 3.1)

```
관찰 1: 동일 변형의 전역적 효과
  동일한 종류의 노이즈 ε을 z에 더하면
  이미지 콘텐츠와 무관하게 동일한 시각적 변화 발생
  (Figure 1: ε 추가 시 모든 이미지에서 유사한 패턴)
  → 노이즈가 콘텐츠 독립적으로 이미지에 영향을 줌

관찰 2: 잠재 코드의 소음 둔감성
  |ε| < ε₀이면 G(z + ε) ≈ x
  (VQGAN의 양자화 과정 때문이지만, KL-regulated 오토인코더도 유사)
  → 비밀 삽입이 이미지를 크게 바꾸지 않을 수 있음
```

**이 두 관찰의 함의:**
- 관찰 2 → 잠재 공간에 비밀을 숨길 수 있음
- 관찰 1 → 출력 이미지에서 숨긴 노이즈를 역으로 복원 가능

### 4.2 "커버 이미지 독립적" 비밀 삽입의 의미

```
기존 방법 (HiDDeN, StegaStamp):
  F(x, s) → stego
  비밀 삽입이 커버 이미지에 의존
  → 새 도메인 이미지에서 성능 저하

RoSteALS:
  δ = F(s)  (커버 이미지 x 입력 없음)
  z_stego = z + δ
  x̃ = G(z + δ)
  → 어떤 커버 이미지에도 동일한 δ 적용
```

**실험적 검증 (Figure 6):**
- 동일 비밀 s를 서로 다른 두 이미지에 삽입 → 잔차(residual) 패턴 유사
- GradCAM 히트맵도 이미지 내용과 무관하게 일정 → 비밀이 전체 이미지에 분산 삽입됨

### 4.3 사전 학습 오토인코더 재사용의 이점 정리

| 이점 | 설명 |
|------|------|
| 학습 용이성 | 이미지 분포 학습 불필요 → 300K 파라미터, ~18 epoch |
| 품질 보장 | 첫 반복부터 오토인코더 품질 수준 보장 |
| 도메인 일반화 | VQGAN이 이미 광범위한 이미지 분포 학습 |
| 확장성 | 더 강력한 오토인코더(Stable Diffusion KL-f8)로 교체 가능 |

## 5. RoSteALS 아키텍처 상세

### 5.1 전체 파이프라인

```
커버 이미지 x (256×256)
        ↓  동결된 인코더 E
잠재 코드 z ∈ R^{H'×W'×C}   (64×64×3, VQ-f4 기준)

비밀 s ∈ {0,1}^L  (L=100비트)
        ↓  비밀 인코더 F (학습 대상, 300K 파라미터)
잠재 오프셋 δ ∈ R^{H'×W'×C}

z + δ
        ↓  동결된 디코더 G
스테고 이미지 x̃ = G(z + δ)
        ↓  노이즈 레이어 (ImageNet-C 14종)
노이즈 이미지 x̃_noisy
        ↓  비밀 디코더 D (학습 대상, ResNet-50 기반)
복원된 비밀 s̃ ∈ {0,1}^L
```

### 5.2 비밀 인코더 F의 구조

```
입력: s ∈ {0,1}^L (L=100비트)
        ↓  완전연결(FC) 레이어
        ↓  SiLU 활성화 함수
        ↓  Reshape + Upsample  (H'×W' 크기에 맞게 업스케일)
        ↓  1×1 합성곱 레이어  (가중치/편향 = 0으로 초기화)
출력: δ ∈ R^{H'×W'×C}

총 파라미터: ~300K (L=100비트 기준)
```

**1×1 합성곱을 0으로 초기화하는 이유:**
- δ = 0 → 첫 반복에서 네트워크가 원본 오토인코더와 동일하게 동작
- 이미지 품질이 학습 시작부터 보장됨
- ControlNet [Zhang & Agrawala 2023]과 동일한 초기화 전략

### 5.3 비밀 디코더 D의 구조

```
ResNet-50 백본
        ↓  마지막 FC 레이어를 L-bit 출력으로 교체
s̃ ∈ {0,1}^L

손실: BCE (Binary Cross Entropy)
```

### 5.4 노이즈 레이어

```
학습 시 삽입되는 노이즈 레이어:
  14가지 ImageNet-C 노이즈

적용 방식:
  - 단일 노이즈 (random individual)
  - 다중 노이즈 동시 적용 (p=0.5):
    대표적 노이즈 (contrast, brightness, JPEG) 동시 적용

비미분 노이즈 처리:
  n(x) = x + [n(x) - x]
  → [.] 부분을 상수로 취급 (gradient 차단)
  → 역전파 가능하게 처리
```

## 6. 손실 함수와 학습 전략

### 6.1 손실 함수

**품질 손실:**
```
L_MSE = ||γ(x̃) - γ(x)||²
  γ(·): RGB → YUV 변환 (미분 가능, 비모수)
  YUV 공간에서 MSE → 지각적으로 더 균일

L_quality = L_LPIPS(x̃, x) + α·L_MSE
  α = 1.5  (LPIPS와 MSE의 균형)
```

**복원 손실:**
```
L_recovery = L_BCE(s, s̃)
  s: 원본 비밀 (ground truth)
  s̃: 디코더 복원 비밀 (predicted)
```

**전체 손실:**
```
L = β·L_quality + L_recovery

β: 품질 vs 복원의 균형 조절 파라미터 (동적으로 증가)
```

### 6.2 동적 β 학습 전략

```
단계 1: 고정 소규모 배치, β=0.1 (복원 우선)
  → 비밀 인코더/디코더를 무작위 비밀로 먼저 학습
  → 이미지 품질은 오토인코더가 보장하므로 걱정 불필요

단계 2: bit acc. ≥ t1 (=90%) 달성 시
  → 전체 학습 이미지셋 해제
  → β를 βmax까지 선형 증가

단계 3: bit acc. ≥ t2 (=98%) 달성 시
  → 노이즈 레이어 활성화
  → βmax = 10 (품질 손실 최대화)
```

**이 전략의 이유:**
```
처음부터 품질 손실(β 높음)을 적용하면?
  → 디코더가 제대로 학습되기 전에 인코더가 δ를 억제하도록 학습
  → 비밀 복원 성능 저하

RoSteALS의 해결:
  복원 먼저 → 품질 점진적 증가 → 마지막에 견고성 학습
  → "쉬운 것부터 어려운 것"으로의 커리큘럼 학습
```

### 6.3 손실 가중치 β와 품질/복원 트레이드오프

```
Figure 8 요약 (Stock1K 벤치마크):
  β_max = 0  → SSIM 낮음(~0.85), Bit acc. 높음(~0.975)
  β_max = 10 → SSIM 높음(~0.90), Bit acc. 중간(~0.925)
  β_max > 10 → 개선 없음 (오토인코더 성능에 의해 상한 결정)

VQGAN 오토인코더 자체 SSIM: ~0.90 (상한선)
```

## 7. 커버리스 및 텍스트 기반 스테가노그래피 확장

### 7.1 커버리스(Cover-less) 스테가노그래피

```
아이디어:
  커버 이미지 없이 잠재 노이즈 z_T ~ N(0, I)에서 시작

문제:
  VQGAN의 잠재 분포가 복잡 → 무작위 z에서 저품질 출력 발생

해결책: LDM(Latent Diffusion Model) 활용
  z_T ~ N(0, I) → LDM 노이즈 제거 → z_0
  z_0 + δ = F(s) → 디코더 G → 스테고 이미지

파이프라인:
  N(0,I)에서 z_T 샘플링
        ↓  LDM (FFHQ로 학습된 무조건부 모델)
  z_0 (FFHQ 분포의 잠재 코드)
        ↓  + δ (비밀 오프셋)
        ↓  디코더 G
  커버리스 스테고 이미지 (얼굴)

중요: RoSteALS 학습 시 LDM 잠재 코드는 전혀 보지 않음
→ 그럼에도 Bit acc. (clean) 0.997 달성 (Table 4)
```

### 7.2 텍스트 기반(Text-based) 스테가노그래피

```
파이프라인:
  텍스트 프롬프트 + z_T ~ N(0, I)
        ↓  Stable Diffusion v1.5 (KL-f8 백본)
  z_0 (텍스트 조건부 잠재 코드)
        ↓  + δz = F(s) (비밀 오프셋, KL-f8 공간)
        ↓  KL-f8 디코더 G
  텍스트 기반 스테고 이미지

RoSteALS 텍스트 변형 설정:
  - KL-f8 오토인코더 백본 (512×512 입력)
  - 비밀 길이 L=64비트
  - MIRFlickR 데이터로 학습 (512×512 리사이즈)

결과 (Table 4):
  텍스트 기반: Bit acc. 0.904, Word acc. 0.844
  커버리스:    Bit acc. 0.924, Word acc. 0.875
```

### 7.3 LDM-RoSteALS의 핵심 장점

```
기존 커버리스 방법 (GAN 기반):
  좁은 도메인 (얼굴, 특정 카테고리만)
  이미지 품질 불안정

LDM-RoSteALS:
  Stable Diffusion의 광범위한 이미지 생성 능력 활용
  텍스트로 원하는 주제의 이미지에 비밀 삽입
  → C2PA 맥락에서: AI 생성 이미지에 자동으로 출처 정보 내포
```

## 8. 실험 결과 심층 분석

### 8.1 데이터셋

| 데이터셋 | 이미지 수 | 특성 | 사용 목적 |
|---------|---------|------|---------|
| MIRFlickR | 100K (학습) + 1K (검증) | 다양한 실생활 사진 | 학습 |
| CLIC | 530장 | 고품질 모바일/전문 사진 | 평가 |
| MetFACE | 1336장 | 예술 작품 속 인물 얼굴 | 평가 (좁은 도메인) |
| Stock1K | 1000장 | 사진, 벡터아트, 스케치, 그래픽 | 평가 (넓은 도메인) |

**평가를 어렵게 만드는 설정:**
- 모든 스테고 출력에 랜덤 ImageNet-C 노이즈 1회 추가

### 8.2 평가 지표

```
이미지 품질:
  PSNR  ↑  (높을수록 픽셀 차이 작음)
  SSIM  ↑  (구조적 유사도)
  LPIPS ↓  (지각적 유사도, 낮을수록 유사)
  SIFID ↓  (단일 이미지 FID, 분포 수준 품질)

비밀 복원:
  Bit acc. (clean)  ↑  (노이즈 없는 스테고에서 비트 정확도)
  Bit acc.          ↑  (랜덤 노이즈 적용 후 비트 정확도)
  Bit acc. (ECC)    ↑  (BCH 오류 정정 후 비트 정확도)
  Word acc.         ↑  (예측 비밀이 정답과 20% 이내 차이면 성공)
```

### 8.3 기준선 비교 (Table 1)

**CLIC 벤치마크 핵심 수치:**

| 방법 | PSNR ↑ | SSIM ↑ | LPIPS ↓ | Bit acc. ↑ | Bit acc.(ECC) ↑ |
|------|--------|--------|---------|-----------|----------------|
| **RoSteALS** | 32.68 | 0.88 | 0.04 | **0.94** | **1.00** |
| StegaStamp | 31.26 | **0.91** | 0.09 | 0.88 | 0.48 |
| SSL | **41.84** | **0.98** | 0.02 | 0.62 | 0.03 |
| RivaGAN | 40.32 | **0.98** | 0.02 | 0.77 | 0.22 |
| dwtDctSvd | 38.96 | 0.97 | **0.01** | 0.61 | 0.16 |

**분석:**
- **이미지 품질:** PSNR/SSIM은 SSL이 최고 (오직 픽셀 변형이 작음), LPIPS는 dwtDctSvd 최고
- **비밀 복원:** RoSteALS가 전 벤치마크 전 지표에서 1위
- **ECC 다양성:** RoSteALS는 0.94 → 1.00 (소폭 오류만 발생하므로 ECC로 완전 복원 가능), 타 방법은 Bit acc.가 낮아 ECC 후에도 개선 폭 제한적

**RoSteALS의 SSIM이 StegaStamp보다 낮은 이유:**
```
StegaStamp: UNet + skip connection → 픽셀 수준 세부 사항 직접 복사
  → 구조적 유사도(SSIM)가 높음 (하지만 시각적 아티팩트 발생, Figure 3)
RoSteALS: 오토인코더 재구성의 상한에 의해 제약
  → VQGAN 자체가 이미 SSIM을 일부 손실
```

### 8.4 RoSteALS 성능의 상한

```
VQGAN 자체 재구성 품질 (CLIC):
  PSNR: 33.90 ± 14.47
  SSIM: 0.90 ± 0.06
  LPIPS: 0.03

RoSteALS의 비밀 삽입 비용:
  PSNR: -1~2 dB
  SSIM: -0.02
  LPIPS: +0.01

결론: 비밀 삽입으로 인한 품질 저하가 매우 작음
→ 오토인코더 자체 재구성 품질이 성능의 천장(ceiling)
```

RoSteALS > StegaStamp인 경우 (전반적으로 우세):

## 9. 한계점 — 어디까지인지까지

### 9.1 오토인코더 재구성 실패 (핵심 한계)

**문제 1: 복잡한 물체 배열**
```
상황: 작은 물체가 밀집된 이미지 (Figure 10, 상단 행)
  커버 이미지의 미세한 공간적 배열을 VQGAN이 정확히 재구성 못함
  → 잔차(residual) 발생 → 품질 지표(특히 SSIM) 하락
  → 시각적으로는 거의 보이지 않으나 측정값에 반영

상황 2: 작은 텍스트 포함 이미지 (Figure 10, 하단 행)
  VQGAN이 작은 글씨를 흐리게 재구성
  → 시각적으로 보임 (품질 지표는 높게 나와도)
```

**근본 원인:**
```
RoSteALS는 오토인코더 성능에 종속됨
→ VQGAN의 64×64 잠재 표현으로 압축되는 과정에서
   고주파 세부 사항 손실
```

**해결 방향:**
- 더 강력한 오토인코더로 교체 (논문이 직접 제안)
- 오토인코더를 스테가노그래피에 맞게 세밀 조정

### 9.2 학습 데이터 도메인 의존성 (잠재적 한계)

```
MIRFlickR로만 학습 → MetFACE(예술 이미지)에서도 잘 동작
But: 매우 다른 분포의 이미지(예: 의료 영상, 적외선)에서는 미검증
```

### 9.3 인코딩 속도 제약 (실용적 한계)

```
현재 RoSteALS: 단일 순전파 (매우 빠름)
                ↳ 커버 이미지 인코딩 → 오프셋 추가 → 디코딩

But 이것도 VQGAN 인코더 + 디코더를 통과해야 함
→ 실시간 고해상도 스트리밍에는 제약 (문제 없는 경우가 더 많음)
SSL과 달리 100회 반복이 없으므로 훨씬 빠름
```

### 9.4 최대 품질의 상한

```
β_max = 10 이상으로 올려도 SSIM 개선 없음
→ VQGAN 재구성 품질이 절대적 상한

비교: SSL은 PSNR 41-42 dB 달성 (RoSteALS는 ~32-34 dB)
→ 픽셀 수준 품질만 본다면 SSL이 우세
→ 그러나 견고성과 SIFID에서 RoSteALS 우세 (목적 차이)
```

## 10. 이 논문에서 파생 가능한 연구 아이디어

### 아이디어 1: 더 강력한 오토인코더 백본으로 교체

**문제:** VQGAN의 재구성 품질이 성능 상한
**확장:**
```
VQGAN (VQ-f4, 256×256) → Stable Diffusion KL-f8 (512×512)
  → 더 높은 해상도, 더 풍부한 잠재 표현
  → 논문에서 이미 실험 (Section 4.5)

더 나아가:
  SDXL VAE (4×다운샘플 → KL-f4) 또는
  최신 이미지 오토인코더 (예: FLUX의 VAE, Cosmos-Tokenizer)
  → 픽셀 충실도 대폭 향상 → 작은 텍스트, 세밀한 패턴 보존
```

### 아이디어 2: 생성 모델 핑거프린팅

**아이디어:**
```
Stable Diffusion의 디코더 G를 파인튜닝하여
  모든 생성 이미지에 자동으로 워터마크 포함
→ "Stable Signature" [Fernandez et al. 2023]으로 이미 구현됨

확장 방향:
  - FLUX, DALL-E 3, Midjourney 등 다양한 생성 모델에 적용
  - 생성 모델 ID + 생성 시각을 비밀로 삽입
  - C2PA 표준과 연동 가능
```

### 아이디어 3: 적응형 페이로드 (Adaptive Payload)

**아이디어:**
```
현재: 모든 이미지에 동일한 L비트 삽입
확장:
  이미지 복잡도(텍스처 풍부도) 측정 → 복잡한 이미지에 더 많은 비트
  capacity(I) = f(texture_entropy(I))

예:
  단순 배경 이미지 → 50비트 (과부하 방지)
  고복잡도 자연 사진  → 150비트

장점: 단순 이미지에서의 Bit acc. 하락 방지
     복잡 이미지에서 더 많은 정보 전달
```

### 아이디어 4: 비밀 삽입의 공간적 제어

**아이디어:**
```
현재: 잠재 코드 전체에 δ 더함 → 비밀이 이미지 전체에 분산
확장:
  마스크 M으로 특정 영역에만 삽입:
  z_stego = z + δ ⊙ M  (⊙ = 원소별 곱)

활용:
  - 인물 사진: 배경에만 삽입 (얼굴 품질 보호)
  - 의료 이미지: 비진단 영역에만 삽입
```

### 아이디어 5: 공격자와의 게임이론적 최적화

**아이디어:**
```
최소최대(minimax) 최적화:
  min_{F,D}  max_{attacker}  [L_recovery(attacked_stego)]

attacker: 워터마크 제거를 시도하는 신경망
→ 서로 강화되는 적대적 학습 (GAN 유사)
→ 더 강한 견고성 달성

현재 RoSteALS는 고정된 ImageNet-C 노이즈만 사용
→ 적응적 공격자에 대한 견고성은 미검증
```

### 아이디어 6: 다중 레이어 워터마킹

**아이디어:**
```
동일 이미지에 서로 다른 비밀 키로 여러 워터마크 삽입:
  레이어 1: 강한 견고성, 낮은 용량 (50비트)
            → "AI 생성 이미지" 표시
  레이어 2: 중간 견고성, 중간 용량 (100비트)
            → 생성 모델 ID + 타임스탬프
  레이어 3: 낮은 견고성, 높은 용량 (200비트)
            → 사용자 ID (재배포 추적)

잠재 오프셋을 여러 개 겹침:
  z_stego = z + δ₁ + δ₂ + δ₃
각 디코더 D₁, D₂, D₃는 해당 비밀 키만으로 복원
```

## 11. 다른 분야에서의 응용

### 11.1 AI 생성 콘텐츠 식별 (C2PA 표준 연동)

```
현재 문제: Deepfake, AI 생성 이미지 급증 → 진위 확인 어려움
C2PA (Coalition on Content Provenance and Authenticity):
  메타데이터로 출처 정보 저장 → 소셜 미디어 공유 시 쉽게 제거됨

RoSteALS 적용:
  생성 모델이 이미지 생성 시 자동으로 워터마크 삽입
  → 메타데이터가 아닌 픽셀에 저장 → 제거 어려움
  → "AI 생성" 여부 + 모델 ID를 비밀로 포함

주의: 카메라 재촬영(물리적 아날로그 변환)에는 취약 가능
→ Figure 10 실패 케이스처럼 미세 변형에 민감
```

### 11.2 디지털 저작권 관리 (DRM)

```
현재 문제: 고가 스톡 이미지의 무단 재배포

RoSteALS 적용:
  구매자 ID (100비트)를 이미지에 삽입
  → 소셜 미디어 재배포 시에도 견고성 유지
  → 재배포 출처 추적 가능

Stock1K 데이터셋에서 이미 평가:
  Bit acc. 0.92 → ECC 후 1.00 (Word acc. 0.864)
  → 사진, 벡터아트, 스케치, 그래픽 디자인 모두 포함
```

### 11.3 의료 이미지 메타데이터 보존

```
현재 문제: DICOM 파일의 헤더와 이미지 분리 → 메타데이터 소실 사고

RoSteALS 적용:
  환자 ID, 촬영 날짜, 장비 번호를 이미지 자체에 삽입
  → JPEG 저장, 화면 캡처 후에도 정보 유지
  → HIPAA 준수: 화면에 보이지 않아 환자 정보 노출 위험 낮음

주의: 의료 이미지(CT, MRI)의 JPEG 압축 특성이 다를 수 있음
→ 도메인별 파인튜닝 필요 가능성
```

### 11.4 박물관/미술관 디지털 아카이브

```
활용 방안:
  스캔된 예술 작품에 기관명 + 작품 ID 삽입
  스마트폰 촬영(물리적 재촬영)에도 견고성 필요 → StegaStamp 수준의 물리적 견고성 추가 연구 필요
  제로비트 감지로 무단 사용 자동 모니터링

MetFACE 데이터셋에서의 우수한 SIFID 성능:
  → 예술 스타일의 이미지에서도 자연스러운 워터마킹 가능
```

### 11.5 연합 학습 데이터 추적

```
새로운 활용:
  연합 학습(Federated Learning)에 사용되는 학습 이미지에 워터마크
  학습된 모델이 워터마크가 있는 이미지를 생성하는지 확인
  → 데이터 출처 증명 가능
  → 데이터 poisoning 공격 탐지에도 응용 가능
```

## 12. 한 줄 핵심 정리

### 논문의 핵심 기여 3줄로

1. **동결된 오토인코더로 '공짜 지식' 활용:** 이미지 분포를 처음부터 학습할 필요 없이, 잠재 코드에 소형 네트워크(300K 파라미터)로 비밀 오프셋만 학습하면 된다 → 경량, 빠른 수렴.

2. **커버 이미지 독립적 삽입:** `δ = F(s)`는 비밀만으로 결정되므로 어떤 이미지에도 적용 가능 → 학습 외 도메인에서도 완벽한 ECC 복원 달성.

3. **잠재 공간의 커버리스 확장:** LDM과 동일한 오토인코더를 공유하면, 텍스트 프롬프트나 무작위 노이즈에서 출발하는 스테고 이미지를 생성 가능 → 스테가노그래피의 새로운 응용 영역 개척.

### 이 논문의 패러다임

```
"이미지 분포는 이미 오토인코더가 알고 있다.
 비밀을 잠재 공간에 조용히 더하라.
 그리고 오토인코더는 나머지를 알아서 처리한다."
```

|------|------|
| 비밀 인코더 F의 크기는? | ~300K 파라미터 (L=100비트 기준) |
| 오토인코더는 왜 동결하는가? | 이미지 분포 학습 불필요 + 품질 보장 + 경량화 |
| 핵심 관찰 2가지는? | ①동일 노이즈의 콘텐츠 독립 효과 ②잠재 코드의 소음 둔감성 |
| 왜 δ = F(s)인가? (x 입력 없음) | 커버 이미지 독립성 → 어떤 이미지에도 적용 가능 |
| 1×1 합성곱을 0으로 초기화하는 이유는? | δ=0으로 시작 → 오토인코더 동작 그대로 → 학습 안정성 |
| 동적 β 전략의 핵심은? | 복원 먼저(β 낮음) → 품질 점진 증가 → 마지막에 노이즈 |
| 비밀 복원 지표에서 1위인 이유는? | 이미지 분포와 비밀 학습의 분리 → 견고성 학습에 집중 가능 |
| SSIM에서 StegaStamp에 지는 이유는? | VQGAN 재구성 품질이 SSIM 상한을 결정하기 때문 |
| 커버리스 스테가노그래피 원리는? | LDM + RoSteALS가 동일 오토인코더 공유 → z_LDM + δ |
| 주요 실패 케이스는? | 클러터 이미지(SSIM 저하), 작은 텍스트 이미지(시각적 아티팩트) |
| SSL과의 핵심 차이는? | SSL은 이미지마다 100회 역전파(느림), RoSteALS는 단일 순전파(빠름) |
| ECC 후 Bit acc.가 1.00인 이유는? | 약 6%의 비트 오류만 발생 → BCH가 완전 복원 가능 |
